Cadence

An AI planner that lives inside Canvas. It reads what's assigned, works out how long each thing will actually take you, and lays it across the free time you actually have.

The demo on the right

A real junior-year week for Fiona: eight assignments, soccer Tuesday and Thursday, piano on Monday, volunteering Saturday morning. Nothing is hardcoded — the plan is computed live.

  • Setup — a one-minute walkthrough instead of a settings page.
  • Today — the one block to start now, with a focus timer and one-tap check-ins.
  • Assignments — ranked by when you have to start, with the reasoning shown.
  • Week — homework blocks side by side with practices and appointments.
  • You — a visual week, activities, pace, and what Cadence has learned.

Try these

  1. Assignments → type history essay due in 3 days, 1000 words and press Add.
  2. Today → tap the circle next to a block, then Longer. Check You afterwards.
  3. You → tap Tue on the week chart and change the times.
  4. You → Teacher tools to dictate an assignment.

Install the real extension

  1. Chrome → chrome://extensions → turn on Developer mode.
  2. Load unpacked → pick the cadence folder.
  3. Open Canvas. The button is bottom-right.

The demo saves to browser storage. You → Start over resets it.
